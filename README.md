# House Price Prediction

## Project Overview

This project aims to predict house prices using machine learning techniques based on various property characteristics such as area, number of bedrooms, bathrooms, parking availability, furnishing status, and other amenities.

The objective is to analyze housing data, identify the factors that influence property prices, and develop predictive models that can estimate house values accurately.

## Dataset

Dataset: Housing Prices Dataset

File Used:

* Housing.csv

The dataset contains 545 records and 13 features related to residential properties.

## Technologies Used

* Python 3
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

9. Feature Importance Analysis

## Model Performance

| Model                   | R² Score |
| ----------------------- | -------- |
| Linear Regression       | 0.653    |
| Random Forest Regressor | 0.612    |

Linear Regression achieved the best performance for this dataset.

## Key Insights

* Area is the most influential factor affecting house prices.
* Bathrooms, air conditioning, parking availability, and number of stories also have a significant impact.
* Larger houses with better amenities generally command higher market values.
* Linear Regression outperformed Random Forest on this dataset.
